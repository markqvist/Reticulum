# Reporting Security Issues

It goes without saying: If you have discovered a security issue in Reticulum or any related project, please report it responsibly to the maintainer over LXMF at `<8dd57a738226809646089335a6b03695>`. If you wish to remain anonymous, please create a disposable identity to send from, and notify us of any such wishes.

If you are not able to use LXMF, you can send an email to the address currently posted on the maintainer's profile on this site.
